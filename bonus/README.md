# 보너스 과제 (선택)

## 보너스 1 — AI 연동 Action (`ai-action/`)
- [ ] 워크플로우에 생성형 AI(ChatGPT, Claude 등) Action 추가
- [ ] 용도: 요약 / 분류 / 템플릿 메시지 중 선택
- [ ] 프롬프트와 입출력 예시, 구성·실행 캡처 저장 (API Key 마스킹!)

## 보너스 2 — 실패 알림 · 재시도 (`failure-handling/`)
- [ ] 오류 발생 시 이메일/메신저로 실패 알림
- [ ] 재시도 또는 대체 경로 1개 이상 (예: 저장 실패 시 임시 시트에 적재)
- [ ] 일부러 오류를 발생시킨 실행 결과 캡처
