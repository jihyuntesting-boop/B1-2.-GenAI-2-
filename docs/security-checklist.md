# 제출 전 보안 점검표

스크린샷 · 문서 · 공유 링크에 아래 항목이 보이면 **마스킹(`***`)** 후 제출합니다.

- [ ] API Key / Access Token / Webhook URL (URL 뒤쪽 고유 문자열 포함)
- [ ] 비밀번호, OAuth 연결 화면의 토큰
- [ ] 계정 이메일 (예: `ji***@gmail.com`)
- [ ] Slack/Discord 채널 · 서버 ID, 초대 링크
- [ ] Google Sheets 공유 링크 (공개 범위 "링크가 있는 모든 사용자" 여부)
- [ ] 실행 로그에 찍힌 개인정보 (이름, 전화번호 등) — 테스트용 더미 데이터 사용 권장

## 팁
- 캡처 전에 테스트용 더미 데이터로 실행한다.
- Webhook URL은 캡처 후 **재발급**하면 노출돼도 안전하다.
- 이 저장소에 `.env`, 키 파일을 커밋하지 않는다 (`.gitignore` 적용).
